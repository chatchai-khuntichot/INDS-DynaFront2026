# Dataset Instructions

## 1. OhioT1DM Dataset (CGM)
Due to the Data Use Agreement (DUA) and patient privacy regulations, the raw OhioT1DM XML files (`559-ws-training.xml` and `559-ws-testing.xml`) are not included in this public repository.

To reproduce the Healthcare CGM experiments:
1. Request access to the **OhioT1DM Dataset** (Patient 559) directly from the official Ohio University SmartHealth Lab portal: http://smarthealth.cs.ohio.edu/OhioT1DM-dataset.html
2. Place the downloaded files into this `data/` directory:
   - `data/559-ws-training.xml`
   - `data/559-ws-testing.xml`

## 2. XAUUSD Dataset (Finance)
- `data/XAUUSD_H1_202305282200_202605280000.csv`: Hourly XAUUSD historical close prices exported from MetaTrader 5.
